# Project Title
Alien hunters

## Project Option
Website

## Project Description
I want the user to see an old message board about poeople who want to hunt aliens

## Theme Interpretation
It has to do with aliens which are space life forms, and people who are seeking the unknown of space.

## Intended User or Player
Someone who's interested in learning more about alien life.

## User or Player Goal
Be able to read and join in on a community of like minded people.

## Main Features
Message board, joining quiz, about page.

## JavaScript Features
Light mode and dark mode toggle, and an alien fact that randomizes each time you load the page.

## Responsive Design
The text and images shrink when the page is sized for different screen sizes.

## User Testing
Lots of people didn't understand the purpose for some pages, and thought it needed more explanation.

## Revisions
I added images, more descriptions, and some better structure.
